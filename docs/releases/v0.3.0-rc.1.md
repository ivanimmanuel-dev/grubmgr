# v0.3.0-rc.1

Adds experimental Ubuntu 24.04, Kali and Arch VM profiles alongside Debian 13.

- One Linux transaction engine selects distro-specific GRUB paths, package versions and boot layouts.
- Arch activation coordinates with pacman's database lock and handles its EFI automount.
- Terminal authentication uses Polkit's separate `pkttyagent`.
- Preview supports Debian-family OVMF and Arch edk2 firmware paths. Ubuntu has an optional application-specific AppArmor profile.
- CI builds and checks both `.deb` and pacman packages.

The [verification report](../linux-verification.md) records authentication, activation, reboots, rollback, recovery, preview and package lifecycle results. Ubuntu's recovery suite and final preview/package checks were completed in separate runs, identified in that report.

Activation is limited to the exact disposable VM profiles in [Linux support](../linux-support.md). Cyberpunk Demo is approved on all four profiles; Starfield remains Debian-specific. Physical-machine and WSL activation, general theme updates, catalog refresh, garbage collection and a GUI are outside this release.
