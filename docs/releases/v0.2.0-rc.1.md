# v0.2.0-rc.1

Experimental Debian VM activation for GRUB themes. Physical-machine activation remains disabled.

- A fixed Polkit helper verifies packages and plans independently of the user store.
- Debian generates a separate candidate, checks it and activates it by synced replacement.
- Immediate recovery restores verified snapshots. Later rollback regenerates against current kernels.
- Starfield imports from a pinned Debian data package with its artwork/font notices intact.
- Optional GRUB/QEMU preview uses a generated menu, no network or host disks, and waits for menu readiness before capture.
- The original fixture backend and normal CI remain separate from real boot tests.

Target: Debian 13.7 amd64, GRUB 2.12-9+deb13u2, Q35/OVMF UEFI with Secure Boot disabled, ext4 root including `/boot`, FAT EFI partition. The full support limits and actual checks are in [Phase 2 verification](../phase2-verification.md).

This candidate is for disposable-VM testing. It does not add Ubuntu/Arch/Fedora activation, a GUI, online catalog refresh, general theme upgrades or garbage collection. Grub of Tsushima has no approved recipe because its third-party asset permissions are unresolved.

The source contains the VM harness. Linux archives contain the CLI, helper and preview adapter; Windows archives contain the fixture CLI. External GRUB/QEMU/Polkit/renderer dependencies and theme assets are not bundled.
